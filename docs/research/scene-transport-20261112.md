# 三期场景网格与 16 MB 资源包边界

预载传输 ZIP 的上限为 16,000,000 字节，且使用 stored 条目。MAP10／12 的完整网格分别为
20,129,296／20,173,324 字节，不能直接装入既有分包；24 MiB 的单资源缓存边界不能代替 ZIP 边界。

Regulation 导出器按每段最多 15,000,000 字节写出 `scene.bin`、`scene1.bin`，最多四段。
`scene.json.binParts` 仅声明固定 `bin`／`binN` 清单键及字节数，`binBytes` 仍为原完整网格长度；
区块偏移、顶点／索引、材质与几何完全不变。加载器先检查数量、固定键、单段大小、实际长度及总量，
再顺序拼接并调用原区块解析器。缺失／截断／非法元数据保留金属棋盘，不解析半份场景。
旧单文件与旧赛季加载方式不变，没有扩大 ZIP 或单资源缓存限制。

[字节收据](scene-transport-20261112.json)显示两图重组后 SHA-256 与原网格完全相同。
两图真实场景文件共 12 个、43,058,456 字节，使用正式分包工具生成 5 个 ZIP，最大
15,014,885 字节；包内每个文件的长度及 SHA-1 均核对一致。其余八图无需拆分。

最终 74 项定向渲染／提取检查通过、无跳过，包含分段加载、缺段回退、元数据边界、实际安装场景与
原有地形 FX／光照／预览检查。MAP10／12 的普通、联防、Boss 共六张 Firefox 1820×1024 实拍均
加载原版场景，无页面、console 或 HTTP 错误；画面保持原几何与材质。截图包含持续效果的时间差，
不宣称逐像素相同。证据位于 `.state/scene-pack-fix-20261112/`。

验证串行运行于 `check:local --small`。测试峰值约 279 MiB，截图峰值约 1.96 GiB，OOM 计数均为零。
完整模拟与 golden 仍按既有要求暂缓，本条不将渲染验证当作玩法回归。
