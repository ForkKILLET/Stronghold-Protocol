# 三期地图光照与沙漠花纹粗调（2026-11-12）

用户授权先按 PRTS 截图拟合，后续积累官服录屏后继续校准。本轮已接入沙漠共用的部分顶点混色，以及十张地图各自的粗光照／白平衡；没有重写原版素材或玩法规则。这些是经验拟合参数，不声称为官服运行时数值。

[调整前／调整后／PRTS 图集](../../.state/map-light-fit-20261112/screenshots/index.html)提供十图三场景，默认展示普通场景，可切换联防、Boss 或全部。相机沿用上一轮标定；MAP04 Boss 仍为同图相机加原版坐标偏移。截图为真实渲染，没有将插值合成图冒充新截图。

## 实现

- `public/js/render/board3d/calibration.js` 独立保存经验参数，严格限定已安装的十张 Regulation composite 场景；旧赛季、未知图、旧格式包和资源缺失回退保持原规则。
- 沙漠主材质 `MT_AutochessSand` 使用客户端已经核对的 COLOR.r / `_BlendRangeCtrl` / `_BlendColor` 分支，共用 **0.625** 的拟合乘数，保留可见花纹。该乘数缩放原材质的混色强度，不改材质文件，不猜逐格遮罩。
- 每图一个 RGB 光照增益，普通／联防／Boss 共用；在显示颜色空间中对光照结果应用，位于独立自发光项、clamp、focus 与输出转换之前。保留本服战场外压暗，不将 PRTS 无压暗的背景直接作为取消该效果的依据。
- Unlit、独立水面、单位及粒子特效保持各自管线。半透明表面不参与拟合；仍保留其透明／alpha 规则，同属 lit shader 的表面跟随该图光照。没有增加全屏滤镜、每帧 CPU 拟合或渲染通道。

## 拟合方法

在本机 Firefox / WebGL2 中，用原版静态几何、原版贴图、烘焙光照和已经标定的真实相机，临时输出 Float32 渲染目标，分别采集：混色 q=0 的漫反射基底、q=1 的漫反射基底，以及独立自发光。采样代码仅在本机研究 harness 中注入，游戏没有调试捕获分支。非目标材质仍参与遮挡但不进入拟合，避免把箱体或水面后的地面误当成可见区域。

目标为 `clamp(gainRGB × (D0 + q × (D1 − D0)) + emission, 0, 1)`。使用材质身份掩码，向内腐蚀 3 像素，轻度平滑缓解剩余相机／重采样误差，并按材质和空间分区限制采样数量，避免远景独占权重。使用 Huber 损失、接近中性增益的正则和 **0.65–1.45** 的有界增益。沙漠五图共用一个 q，每图只有三个光照参数；不增加每格、每场景的独立系数。

## 实际渲染复验

拟合后重新加载正式 shader，重拍 30 张桌面截图，并重新输出实际 Float32 结果，逐项对照拟合预测。全部 30 个场景的采样误差均下降，实际 shader 输出与预测的最大差异小于 0.15 色值（实际约 0.0001），确认并非只在图像插值上改善。所有截图无页面、console 或 HTTP 错误。

72 项定向渲染检查全部通过、无跳过；覆盖参数边界／旧包隔离、原材质不被改写、原 alpha 规则，以及场景／地形效果／投影既有检查。完整模拟与 golden 继续暂缓。重任务串行使用 `check:local --small`；原始基底捕获 scope 峰值约 2.74 GiB，最终捕获不超过约 2.10 GiB，OOM 计数均为零。

数值与来源 SHA-256 见同名 JSON。本机原始基底、前后截图、验证日志位于 `.state/map-light-fit-20261112/`。拟合器为 `tools/research/fit-regulation-light.py`，依赖 NumPy 与 OpenCV，命令示例：

```sh
npm run check:local -- --small python tools/research/fit-regulation-light.py \
  --basis .state/map-light-fit-20261112/basis \
  --references .state/regulation-prts-view-20261112/references \
  --out .state/map-light-fit-20261112/fit.json
```

## 仍待后续录屏核对

当前版本没有声称完整还原官方 shader。反射／法线／粗糙度、动态阴影、水面及后处理仍有差异；PRTS 图片版本、剩余几何／相机误差和缩放也影响拟合结果。后续优先用同版本、同场景、固定画质的原尺寸截图或录屏确认运行时材质／主题参数，再逐步替换经验近似，不把此次系数推广到旧赛季或所有干员特效。此次修改仅在本机，未推送部署。
