# 隐匿地块红光遮挡（2026-11-12）

用户指出图 9 最下方隐匿格的红光底边透出前方整备台；PRTS 原图中该边被遮住。

原因是 TerrainFx 使用独立 OfficialFx，在 Pixi 的 WebGL 上绘制，不能继承下层 Three.js 画布的深度。原版隐匿特效材质已有 LessEqual 深度测试，但此独立通道从未调用 setGround，深度预通道只清空缓冲，没有地形可写入。

修复在创建／切换地图循环时，通过既有 setGround 提供当前可见棋盘的实际格面高度，包含原版资源校准后的整备台／高台；不可见区域按零高度处理，避免其它场地形成不可见遮挡。稳定帧复用深度几何，地图／可见区域／特效档位变化时重建。保留原版材质和红光几何，不裁剪下边、不改变特效位置或全局战斗特效排序。

[截图对照页](../../.state/terrain-depth-20261112/screenshots/index.html)包含 MAP09 普通／联防／Boss 的修正前后与 PRTS，以及 MAP11 的无该效果对照；首页提供最下方格子的局部三图对比。六张修正后截图均使用 Firefox、1820×1024、DPR 1，复用上一轮相机参数，确认 GL 深度可用、特效实例完整，无页面或 HTTP 错误。

定向检查 `terrainfx.test.js`、`vfx-frame.test.js` 共 13 项全部通过，覆盖整备台高度、隐藏地块排除、稳定帧复用、可见区域变更及既有深度高度场／投影。测试及截图串行执行于 check:local --small；截图 scope 峰值约 1.67 GiB，OOM 计数为零。完整模拟与 golden 仍暂缓。此次仅源码变动，没有重提取或改写原版资源。
