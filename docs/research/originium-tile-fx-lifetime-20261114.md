# 活性源石地板红光生命周期（2026-11-14）

玩家反馈对局中没有红光，进入联防时短暂闪现。

## 显示条件

三期原版场景的 `tileEffects` 将活性源石地块映射到 `map_promote_01`。
`TerrainFx` 在 3D 棋盘、官方特效开启（完整或精简）、清单存在该资源且地块当前可见时创建特效。
资源异步就绪后开始绘制，不依赖地块上有无干员、是否触发地形增益或当前是否处于战斗。
实例使用独立于战斗清场的 `OfficialFx`；普通／联防／Boss 可见区域切换时释放旧实例、创建新实例，关闭特效或销毁棋盘时释放。
绘制仍使用原版深度测试和可见地形高度，前方整备台可以遮挡红光。

## 原因与修复

本机官方客户端提取的 `battle/prefabs/effects/map.ab`／`map_promote_01` 描述：

- 根行为为 `Torappu.Battle.Effects.MapEffect`，没有 `ParticleEffect._isLoop`。
- 红光来自四片静态 Quad，使用 `map_promote_04` 溶解材质，`_MainUSpeed=0.5`。
- 父节点附带一个持续 2 秒的非循环粒子系统，粒子渲染器禁用，没有实际发射粒子。

原播放器没有识别 `MapEffect`，因此按普通一次性粒子特效判断完成；真实描述在 60 Hz CPU 步进下约 2.0167 秒结束，连带四片仍应存在的网格一起消失。`TerrainFx` 的 `loop:true` 只保证迟到加载不被丢弃、免除无人管理的一次性 TTL，并不会把有限粒子或静态网格改为循环。稳定区域不重新创建已结束的实例；切换联防后才重新创建，因此短暂重现。隐匿地块和沼泽的粒子本身循环，掩盖了同一管理路径对静态地图特效的遗漏。

修复在通用特效编译及生命周期中识别 `MapEffect`，播放时由地图持有实例；有限粒子仍正常结束，静态网格和连续材质时钟继续存在。保留结束延迟、显式 stop／kill、清场、池复用、已有最大时长和普通一次性特效规则；不按地图／特效 ID 写例外，不重置时钟或重复发射粒子，不改资源、shader、深度或游戏规则。

## 验证范围

- 自动定向回归覆盖完整／精简下有限粒子结束后静态网格继续提交、连续时钟、显式停止、销毁、池复用、禁用 MapEffect 和普通特效结束；并复验既有地形深度与区域切换。
- 使用实际提取的源石／隐匿／沼泽描述，经真实 `TerrainFx` 和 `OfficialFx` CPU 步进，完整／精简分别普通 60 秒、联防 60 秒；四片源石网格持续提交，旧区域实例释放，关闭后无残留。
- 本轮未运行 GPU／浏览器截图、完整模拟或 golden，CPU 验证不能证明最终像素效果。
