# Fork：同步 xinhai 0.3.0

本次从 `aa2668c2` 合入 `xinhai-ai/master` 的 `5160d018`（0.3.0）。
主线插件、官方特效、皮肤、语音、场景、AI、资源分包及规则更新沿用 xinhai 实现。

## 保留的部署功能

- 房间统一配置、休整期倍率、1–4 倍速、全局一致暂停、跨战场查看、逐回合作战记录。
- 等待室／策略选择交流、队友预选、满房音效、装备／悬赏界面隐藏。
- 免登录的 SQLite 博士档案、恢复码、服务器本人结算和 PRTS 个人头像。
- 新大厅的成就入口打开博士档案；房间立绘／干员皮肤与服务器个人头像独立。

## 减少上游差异

统计继续使用上游 v2；`matchId` 仅为可选字段，不单独增加 v3。
统计与成就的上游纯计算移至 `shared/`，浏览器与 SQLite Worker 复用同一算法。
账户累计与成就覆盖全部本人服务器记录，不依赖历史分页；旧本机明细仅补充历史，不自动上传。
玩法插件对局保存房间内容身份，默认不计入累计；“含插件对局”显式包括，纯外观仍计原版。

插件 Host 的参数转发补齐休整期、倍速和账户结算开关，保留进程隔离。
多人自选库存和控制台装备免库存均接受 xinhai 0.3.0 规则，不保留旧规则分支。

## 冷更新策略

更新前进入维护状态、禁止新开局，等待进行中的对局全部结束，并让结算／重试 outbox 写入完成。
优雅停止旧服务后再清理旧房间、会话、队列及对局快照，随后启动新版。
Redis 若与其他服务共用，不清空整个数据库；只处理本服务的运行态键。
不删除 SQLite 用户库、凭证、恢复码、头像、历史结算及持久化卷。
同版本仍保留自动重启恢复，不新增跨版本进行中对局的迁移承诺或测试矩阵。

生产部署必须同时更新对应素材清单与文件。旧镜像只有 0.2.4 素材，不能据此声称已提供全部新特效／场景／语音。
插件工作台所需工具、schema、模板及指南进入运行镜像；只读容器使用独立可写 plugins 卷和所需临时目录。
脚本默认关闭、房间默认原版。不自动启用 R2 或第三方插件，也不改变 7999、Traefik、Redis 和账户卷。
本次仅源码合并，不重建线上服务。
