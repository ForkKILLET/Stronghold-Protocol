# 干员语音字幕

设置 → 干员语音附近提供两项本机偏好：

- **显示字幕**：默认关闭（`voiceSubtitles`）。关闭时不加载字幕数据。
- **其它语种字幕**：仅 UI 语言／双语／仅语音语言（`voiceSubtitleMode: ui | dual | voice`），默认仅 UI 语言。

字幕订阅 AudioManager 实际开始／结束的语音，覆盖选中、部署、技能、结算和试听。随机句、个人配音、本土配音和加载失败回退均根据最终播放文件匹配；只显示当前一句，不建立字幕队列。被调度丢弃、尚在加载、失败或静音的语音不显示。切后台及 AudioContext 暂停隐藏，恢复跟随音频时钟，不随战斗倍速缩短。旧句的异步文本／音频回调不能替换新句。

鼠标悬停台词条时固定当前句，语音结束或新句开始也不会消失／替换，边框以薄荷色提示保留状态。移开后直接跟随仍在播放的新句，没有语音则收起，不排队补放旧句；不暂停语音或战斗。触摸设备仍穿透台词条，不会因轻点卡住。静音、切后台、音频暂停、关闭字幕、切换页面／语言／字幕模式及面板遮挡会解除保留。

台词条使用主题方角、深色背景、薄荷色干员名。名称独占一行，较长时换行，不用省略号；正文使用整条宽度。对局内右对齐到“准备就绪”按钮左侧，顶栏的不可交互锚点在战斗阶段继续保留，不限时休整也保留倒计时区域高度，避免锚点抬进回合栏；宽度按窗口尺寸在 280–400px 之间调整，不随商店、EFFECTS 列表或详情卡移动。测量换行高度后避让回合条、实际盟约图标、详情卡、盟约说明及其它 HUD／面板，重叠或空间不足时暂隐，不自动换位。窄屏可收起盟约条腾出空间。详情卡原有自动换边逻辑保持不变。局外试听继续按底部空隙在 280–520px 之间调整并避让操作按钮。关闭覆盖面板后仅恢复尚在播放的句子，不补放旧台词。桌面每种语言最多两行，矮屏每种语言一行。

## 数据和语言

`data/voice-captions/{zh,en,ja,ko,zh-TW}.json` 按需从本站／DATA_CDN 读取，按完整 `wordKey/voiceId` 保存纯文本。不能只用 charId 或技能编号匹配，也不能从 `cn_025` 文件名判断语言（所有配音共享编号）。实际目录 `voice/cn|jp|en|kr` 决定配音语言，本土目录结合 `voiceNativeLangType`。

双语先显示语音原文、再显示 UI 译文；相同语言（含简繁中文）或相同文本只显示一次。部分本土配音仅有翻译文本，不能冒充意大利语等原文：仅 UI 模式可显示译文，双语缺原文时只显示译文，仅语音语言模式缺原文时不显示。未知插件音频或缺失台词不猜测，不阻塞播放。

生成源固定在 `tools/voice-caption-sources.json`，包含 URL、Git revision 和 SHA-256。只生成当前干员／自选干员／语音清单涉及的台词，不修改玩法数据或素材清单。更新源后运行：

```sh
node tools/build-voice-captions.mjs
node tools/build-voice-captions.mjs --offline
```

原表缓存在 `.cache/voice-captions/`，不提交。生成字幕文本随 Git／镜像发布，不进入素材预载 ZIP；开启字幕后按所需语言读取，不额外下载语音。

验证：`test/ui/voice-subtitles.test.js`、原音频／设置／i18n 回归，及 `SP_E2E=1 node --test test/ui/voice-subtitles.e2e.test.js`（Chrome／Firefox，真实 HUD 截图和 Web Audio 播放生命周期）。
