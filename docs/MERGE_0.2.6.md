  `SP_WS_COMPRESSION` 开关、双向无上下文复用、公告、网络诊断、Worker 与状态增量。

  保留音频 Range、条件请求、普通素材一天缓存和 Vite 构建分包 immutable 策略。

  转换后继续按实际字节维护本分支 SHA-1 素材指纹。
- 服务端 HTTP / WebSocket 流量计数与客户端诊断下载量。共享分类拆为 `shared/traffic.js`，
  不依赖排除的哈希 URL 工具。普通 `/healthz` 保留轻量缓存快路径；
  可信本机 / 内网的显式 `/healthz?traffic=1` 附加实时计数，公开访问只返回普通健康状态。
- 官方场景 `direct` / `indirect` 恢复为 1，显示场景时补画射击台、水上平台及封印地面。
- 干员部署 / 回合开始的入场动画与独立落地音效池、可选且默认关闭的弹药数量显示。
- 模型缓存按动作测量范围、每槽裁切和大动作直接绘制、冻结模型首次姿态修复。
- 最后一位待选策略的玩家不可跳过；维什戴尔魂灵之影仅召唤到本场可部署战场，
  保留队友半场，排除整备区及单人首领战的空半场。
- 上游测试、工具、文档及版本元数据同步，保留本分支 CDN、预载 / ZIP、帧率设置、
  移动端布局、聊天 / 审核、统计、匹配、持久化、库存来源和 Boss / 盟约规则。

本标签的光照修复为 PR #554 的增益部分；不包含审阅过但不在该标签内的 PR #571，

`/assets/~hash/`、`/fonts/~hash/`、`/media/~hash/` 路由，以及相应的素材一年 immutable
缓存、内容索引 ETag、音频改写、文档和测试预期。

移除功能同时保留混合文件的独立更新，不用整文件 ours/theirs 解决冲突。

无哈希别名路由及原有指纹字段不变；`test/traffic-category.test.js` 验证独立流量分类。

这不排除现有预载 / ZIP 的内容指纹和字节校验，也不排除 Vite 哈希代码分包。
