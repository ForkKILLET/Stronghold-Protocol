## 更新公告

这是一个 **Markdown 文件**示例：编辑这个文件即可调整正文，不必在 JSON 中转义换行。

### 功能

- 支持标题、**粗体**、*斜体*、~~删除线~~、列表和表格。
- 支持多个 [项目链接](https://github.com/xinhai-ai/Stronghold-Protocol)。
- 支持 HTTP(S) 图片或站内图片：

![项目图标](/icons/app-192.png)

| 项目 | 说明 |
| --- | --- |
| 时间 | 不填开始或结束时间即可长期展示 |
| 自动弹出 | 在 JSON 中设置 `autoPopup: true` |
| 撤回 | 在 JSON 中设置 `enabled: false` 或移除条目 |

> 不执行原始 HTML、JavaScript 或任意 CSS；它们不会成为可执行内容。
